# Proyecto Intermodular ASIR

## DogRelax

Bienvenido a la documentación del **Proyecto Intermodular de ASIR**.

Este proyecto tiene como objetivo diseñar e implementar una infraestructura informática para **DogRelax**, un centro de bienestar y spa canino situado en Talavera de la Reina.
